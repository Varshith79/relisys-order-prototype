# Relisys order app prototype

Clickable prototype of the Relisys customer order app, on an Android and an iPhone frame.

Open `index.html`, or the GitHub Pages link for this repository.

Products, item codes, order numbers, delivery challans, invoices, dates and quantities come from Relisys SAP Business One. All customer and staff details (names, codes, mobile numbers, emails, GSTINs, addresses) are sample data.
